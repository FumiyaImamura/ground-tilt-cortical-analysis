# Data availability and repository scope

## Data included here

The `source_data/` directory contains compact arrays and tables used by the figure
workflows in this repository. These files allow the included panels to be generated
without downloading the much larger imaging and video datasets.

## Larger datasets

Raw two-photon movies, behavior-camera videos, and larger processed datasets are
distributed separately as described in the paper's Data Availability statement.

## Platform-control software

The six-degree-of-freedom platform-control software, firmware, CAD files, and
engineering documentation are maintained separately from this cortical-analysis
repository.
